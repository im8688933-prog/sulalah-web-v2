# سلالة — مشجرة بني أمغيان

واجهة عربية RTL تتكيّف بين شاشة الكمبيوتر للمشرف وشاشة الهاتف للقراءة فقط. المشجرة تبدأ فارغة حفاظًا على النسب الحقيقي.

## المزايا

- إضافة الأشخاص وتعديلهم وحذفهم على الكمبيوتر بعد تسجيل دخول مشرف.
- ربط الأب والأم، بحث بالاسم والفرع، وعرض شجرة تفاعلية.
- مزامنة سجل العائلة عبر مشروع Supabase القائم باستخدام مصادقة المشرف وسياسات RLS الموجودة.
- ربط الهاتف برمز QR مؤقت أحادي الاستخدام؛ حساب الهاتف للقراءة فقط.
- تصدير نسخة JSON واستيرادها من لوحة الكمبيوتر.

## الاستخدام المحلي

افتح `index.html` بمتصفح حديث. الاتصال بقاعدة Supabase والكاميرا يحتاجان استضافة HTTPS. الرابط العام للتطبيق يفتح وضع قراءة فقط على الهواتف؛ يسجل المشرف الدخول من الكمبيوتر وينشئ رمز ربط جديدًا لكل هاتف.

لا تضف أسماء حقيقية محليًا قبل الاتصال بالمشرف؛ النسخة تحفظ تعديلات الكمبيوتر محليًا ثم تزامنها بعد تسجيل الدخول. لا تحفظ كلمة مرور الحساب في التطبيق.

## الملفات

- `index.html` واجهة الكمبيوتر والهاتف.
- `app.js` المشجرة وبطاقات الأفراد والنسخ الاحتياطية.
- `sync.js` المصادقة والمزامنة والربط المؤقت للأجهزة باستخدام قاعدة Supabase القائمة.
- `styles.css` و`sync.css` تنسيقات الواجهة.
